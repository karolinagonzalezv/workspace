1.¿Qué es una función?

r/ Es un código reutilizable que realiza una tarea específica , Se define una vez y se puede usar muchas veces.

2.¿Qué son los parámetros?

r/  Son variables que una función recibe como entrada. Se definen entre paréntesis al crear la función.

3.¿Qué hace return?

r/ Devuelve un valor desde la función y detiene su ejecución.

4.¿Qué diferencia hay entre Node y React?

r/ Node 
-Entorno de ejecución para JavaScript en el servidor
-se ejecuta en la terminal
-Maneja bases de datos, archivos, lógica
   
   React
-Librería para construir interfaces de usuario
-Frontend, componentes visuales
-Se ejecuta en el navegador
-Maneja la vista y la interacción del usuario

5.¿Qué hace useState?

r/ React que permite agregar estado (datos que cambian) a componentes funcionales.

6.¿Por qué usamos Number() en React?

r/ Para convertir un valor a número.
